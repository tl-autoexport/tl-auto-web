# TL Auto — модель транспорта и источников

## Решение CP-03

В текущем релизе публичный каталог работает только с автомобилями из Encar.
Мотоциклы, скутеры и гидроциклы не выводятся в интерфейс и не импортируются,
пока для них не утверждены отдельные источники и правила расчёта.

## Общая модель

Таблица `cars` сохраняется как текущая физическая таблица для обратной
совместимости с каталогом и расчётами. В неё добавляются общие поля:

- `vehicle_type` — тип транспорта: `car`, `motorcycle`, `scooter`, `jetski`;
- `vehicle_specs` — JSONB для характеристик, специфичных для типа транспорта.

Общие поля остаются реляционными: источник, внешний ID, ссылка, марка, модель,
год, цена, фотографии, статус, дата обновления и расчёт. Категорийные параметры
не смешиваются в автомобильные поля.

## Матрица источников

| Тип | Источник | Статус | Публичный интерфейс |
|---|---|---|---|
| Автомобиль | Encar | активен | показывается |
| Мотоцикл | не выбран | исследование | скрыт |
| Скутер | не выбран | исследование | скрыт |
| Гидроцикл | не выбран | исследование | скрыт |

## Правила активации новой категории

1. Подтвердить источник и допустимый способ получения данных.
2. Описать поля в `vehicle_specs` и правила нормализации.
3. Отдельно определить калькулятор, валюту, доставку и юридические ограничения.
4. Добавить импорт в отдельную команду, не меняя Encar importer.
5. Провести checkpoint и только после согласования вывести категорию в UI.
