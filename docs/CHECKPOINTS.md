### Технические замечания

- Реальные ключи Supabase не записаны в репозиторий.
- Для локальной CI-проверки без базы используется только `TL_AUTO_BUILD_WITHOUT_CATALOG=true`; в deployment включать его запрещено.
- В схеме, отдельных внутренних типах и неактивных нормализаторах пока сохранены старые nullable-поля/помощники HeyDealer для совместимости унаследованных миграций. Они не являются разрешённым источником, не участвуют в публичной выборке и не имеют команд импорта. Их удаление будет оформлено отдельной миграцией и cleanup на этапе модели данных.
- `npm` сообщает о 2 high severity зависимостях; автоматический `npm audit fix` не запускался, чтобы не внести неконтролируемые breaking changes.
