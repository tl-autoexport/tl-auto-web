## Важное наблюдение

Число `reportedTotal` — официальное значение `<last>` из ответа Passo. Число `unique parsed` ниже него, потому что часть страниц содержит повторяющиеся/служебные элементы и записи, которые источник показывает в выдаче, но не отдаёт как уникальный стандартный `<item>` с полноценным ID. Поэтому для проектирования импорта ориентируемся на `reportedTotal`, но перед записью в базу нужно отдельно определить:

- какие элементы являются реальными объявлениями;
- какие объявления относятся именно к мотоциклам/скутерам;
- какие записи имеют дату и главное фото;
- как источник помечает гидроциклы внутри `section=boat`.

Текущий результат даёт безопасную оценку порядка объёма: около 5,8 тыс. свежих мотообъявлений и около 0,66 тыс. свежих водных объявлений на момент аудита. Это не импорт и не финальная гарантия количества.

## Решение по этапу 3

Технически read-only пагинация работает, источник стабильно отвечает, фотографии доступны. Запись в Supabase пока не выполнялась.

Следующий checkpoint — этап 4: выборочно разобрать карточки по страницам и справочникам, отделить мотоциклы/скутеры/гидроциклы, проверить названия полей и сформировать точные правила исключения. Только после этого можно готовить пилотный импорт 20–30 объявлений.
