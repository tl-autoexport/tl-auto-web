# TL Auto — карта источников и данных

## Источники

| Категория | Источник | Статус |
|---|---|---|
| Автомобили | Encar | утверждён |
| Мотоциклы | отдельный источник | требуется исследование |
| Скутеры | отдельный источник | требуется исследование |
| Гидроциклы | отдельный источник | требуется исследование |
| HeyDealer | не используется | исключён |

## Правило переноса

Переносим структуру и разрешённую бизнес-логику, но не подключаем TL Auto к production-базе Autoexport и не строим новый проект на чужом API Opncar/Kurilo.

## Целевая модель

Общие поля транспорта: категория, источник, внешний ID, марка, модель, год, цена, фотографии, ссылка, город, статус и дата обновления.

Специфические характеристики добавляются по категории, а не смешиваются в единую автомобильную модель.
