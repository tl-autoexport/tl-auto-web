## Scope and handling

- Target is the 18 unique listings / 18 configurations whose Korex result had no candidate after the completed EncarRus, Danawa, and Korex passes.
- This report is an independent research pass against public Korean-market specifications and manufacturer announcements. It does not repeat EncarRus, Danawa, or Korex requests.
- Power is recorded in PS, matching the Korean source convention and the project reference convention.
- These are proposed research values only. No database or public catalog writes were made; no value is approved by this report alone.
